# 🔍 半角かっこ閉じ忘れチェッカー (Bracket Checker)

ソースコードやテキスト内の半角かっこ（ `()` `{}` `[]` `<>` ）の閉じ忘れや対応のズレを瞬時に検出・可視化するブラウザ完結型のWebツールです。✨

🚀 **Web版はこちら:** [https://MrHiraiwa.github.io/bracket-checker/](https://MrHiraiwa.github.io/bracket-checker/)

---

## 💡 特徴

- ⚡ **リアルタイム精密診断**: かっこの総数バランス（開き vs 閉じ）と構文上のネスト（入れ子）不整合を同時にチェック。
- 🎯 **迷子ブロックの特定**: 深いネストで閉じ忘れが発生した際、最も原因として疑わしいブロックをハイライト表示。
- 🛡️ **コード解析モード対応**: JavaScript/TypeScript/C/Java等のソースコードに含まれるコメント（`//`, `/* */`）、文字列リテラル（`""`, `''`, ` `` `）、正規表現リテラルを自動マスクして誤検知を防止。
- 🔒 **完全クライアントサイド動作**: 入力したコードやテキストは外部サーバーに一切送信されず、すべてブラウザ内で安全に完結します。

---

## 🎯 対応かっこ一覧

- **丸かっこ**: `()`
- **波かっこ**: `{}`
- **角かっこ**: `[]`
- **山かっこ**: `<>` *(オプションでON/OFF可能)*

---

## 🛠️ 使い方

1. [公開ページ](https://MrHiraiwa.github.io/bracket-checker/) にアクセスします。
2. テキストエリアにチェックしたいコードや文章を貼り付けます。
3. 必要に応じてオプション（コメント・文字列除外 / 山かっこチェック）を設定します。
4. **「チェック実行 🚀」** ボタンをクリックすると、不整合の発生行と該当プレビューが表示されます。
