# 🔍 インデント整形 ＆ 階層レインボーかっこチェッカー (Bracket Checker)

AI生成コードや長大なスクリプトで発生する「かっこの閉じ忘れ」「余分な閉じかっこ」「関数の飲み込み事故」を肉眼とAIスコアリングで瞬時に検出・修正できるブラウザ完結型のWebツールです。✨

ガタガタになった行頭スペースの自動整列（フォーマッター）や、階層の深さを色付きバーで可視化するレインボーインジケーターを搭載しています。

🚀 **Web版はこちら:** [https://MrHiraiwa.github.io/bracket-checker/](https://MrHiraiwa.github.io/bracket-checker/)  
📖 **開発ストーリー（note）:** [GASでコードが長くなりすぎて「かっこ迷子」になったので、ブラウザ完結のチェッカーを作った話](https://note.com/modern_echium586/n/ne000eff3d5ac)

---

## 💡 主な機能・特徴

- 🕵️‍♀️ **被害者ではなく「真犯人（ズレの発生源）」を特定**
  - 単にエラーになった末尾の行や孤立したかっこ（巻き込まれた被害者）ではなく、「前の関数に飲み込まれている境界線」を自動検知。どこで壊れたのかを確率付きランキングで特定します。
- 🌈 **視覚で捉える「階層レインボービューアー」**
  - 行番号の横に、ネスト（深さ）の数だけカラーバーが縦に伸びるインジケーターを搭載。
  - 対応するかっことバーの色が完全連動するため、スクロールするだけで「帯が下に突き抜けて伸びている＝閉じ忘れ」が肉眼で一目瞭然です。
- 🧹 **AI生成コードの行頭を一発整列（インデントフォーマッター）**
  - AIとの壁打ちコピペで崩れた行頭のインデントを、かっこの深さに応じてスペース2個ずつに自動整形。修正した行数もリアルタイムで把握できます。
- 📁 **ローカルファイル読込 ＆ 日時付きダウンロード**
  - `.js`, `.gs`, `.txt` などのファイルを直接ドラッグ＆選択して読み込み可能。
  - 整形・修正後のコードを `元のファイル名_YYYYMMDD_HHmm.js` 形式でワンクリック保存できます。
- 🛡️ **コメント・文字列の自動マスク（誤検知防止）**
  - コメント（`//`, `/* */`）や文字列リテラル（`""`, `''`, ` `` `）、正規表現の中に含まれる記号を自動で除外して精密に解析します。
- 🔒 **安心の完全クライアントサイド動作**
  - 入力・読み込みしたコードは外部サーバーへ一切送信されず、すべてお使いのブラウザ内部で安全に処理されます。

## 🛠️ 使い方

1. [公開ページ](https://MrHiraiwa.github.io/bracket-checker/) にアクセスします。
2. チェックしたいコードをテキストエリアに貼り付けるか、「📁 ファイルを選択して読み込む」ボタンからコードファイルを読み込みます。
3. 必要に応じて各ボタンをクリック：
   - **🧹 行頭インデントを自動整列**: ガタガタな行頭スペースを綺麗な階層構造に一括整形します。
   - **🔍 真犯人スキャン ＆ 階層可視化**: 閉じ忘れ・余分なかっこを解析し、真犯人候補とレインボービューアーを表示します。
   - **📋 コピー** / **💾 保存 (DL)**: 修正済みのコードをクリップボードやファイルとして取り出せます。
